How to follow up, fix details, and track checks

A teacher hasn't sent their recommendation

Open the application and find Teacher Recommendation. Email the request sends the teacher their private link again. If the address is wrong, use Change teacher first, then send. Changing the email address makes a new link, and the old one stops working.

Request failed in the list means the email service refused the message, usually because the address is mistyped. Sent means the service accepted it. It can't tell us whether it reached the inbox or the spam folder, so if a teacher says they never got it, ask them to check spam, or use Copy private link and send it yourself.

The student gets an email automatically when their recommendation arrives.

Fixing a typo or a changed college

Open the application and press Edit on General. Saving never emails anyone. The student's original answer stays visible under the field and in Change History. Grades, scores and essays can't be edited here.

Two applications with the same phone number

Brothers and sisters can both apply, so a shared phone number is accepted and flagged instead of refused. If they're different students, press They're different students. If it's the same student applying twice, keep the first application and mark the later one Not awarded with a note. A repeat email address is still refused automatically.

Tracking a check until it's cashed

After awarding, open the application and use Record a check under Scholarship Check. Press Update when it's handed out and again when it shows up on the bank statement. Every date is optional. Leave one blank rather than guess.

If a student loses a check, set it to Reported lost. That doesn't stop payment, so call the bank. Then use Record replacement check. Once the bank confirms the stop payment, set the old check to Voided. Only the newest check counts toward the money still out, so a replacement is never counted as a second award.

Export Checks downloads every check, including replaced ones, for comparing against bank statements.
